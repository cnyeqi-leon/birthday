照片放这里
==========

把 6 张照片命名为 1.jpg、2.jpg … 6.jpg，放进本目录（assets/photos/），
刷新网页就会自动替换掉占位图，不用改任何代码。

· 支持 jpg / png / webp，但 index.html 里写的是 .jpg；换格式要改 index.html 顶部 CONFIG.photos 里的 file。
· 建议竖图（4:5）或者能裁成竖构图的照片，卡片会自动 object-fit: cover 裁切。
· 单张控制在 1MB 以内，手机上打开更快。

占位卡片的标题（夜骑 / 镜头 / 夜 / 跑道 / 远方 / 十七）在 index.html 的 CONFIG.photos 里改。
